Hostile fixture

Real-world DOM structures that a naive document.querySelectorAll traversal cannot see. Each case is labelled with what should be found.

1. Open shadow DOM expect: 1 input + Aadhaar

2. Nested shadow DOM, 3 deep expect: 1 button + PAN

3. Closed shadow DOM expect: unreachable, by design

A closed root is not reachable from page script. Anything inside it is invisible to extraction — and, importantly, its pixels are still captured in the screenshot.

4. Same-origin iframe expect: card + input

Payment fields live in iframes on most real checkouts. The card number below is rendered into the screenshot whether or not a content script runs in this frame.

5. Canvas-rendered button expect: no DOM node exists

Drawn pixels only. There is nothing in the DOM to find — this is precisely the case a screen-reading pass is for.

6. Virtualised list expect: only the visible window

1,000 logical rows, ~6 in the DOM. Row 500 holds an IBAN that is not present in the document until scrolled to.

7. SPA route change expect: URL changes, no page load

current: /hostile-realworld.html

8. Late-mounted content expect: appears after ~400ms
